Una red de cuentas con contenido IA, operada por API

Qué permite hoy cada plataforma para publicar video corto sin subida manual, qué demografía entrega cada API para el dashboard, y el plan para pasar de 5 a 50–100 cuentas sin poner en riesgo la operación.

Agosto de 2026 · Investigación verificada contra documentación oficial de TikTok, Meta y Google

Respuesta corta

Sí es viable: las cuatro plataformas permiten subir video por API oficialmente. El código no es el cuello de botella — los trámites sí: TikTok y YouTube exigen auditar la app antes de que los posts salgan públicos, y Meta exige App Review. Tres hallazgos definen el diseño de toda la operación:

HALLAZGO 1
La auditoría es el camino crítico, no el desarrollo
Sin auditoría, TikTok fuerza los posts a modo privado (y máx. 5 cuentas publicando) y YouTube bloquea los videos como privados. Iniciar los trámites el día 1; mientras tanto, la integración TikTok de Higgsfield (ya auditada) permite publicar en público desde ya.
HALLAZGO 2
Demografía edad/sexo por video: solo YouTube
TikTok e Instagram entregan edad/sexo únicamente a nivel de audiencia de la cuenta (y con ≥100 seguidores). El dashboard se diseñó para ese mundo real: demografía por cuenta cruzada con métricas por video.
HALLAZGO 3
El riesgo no es tener 100 cuentas — es clonar contenido
Las políticas de comportamiento inauténtico (Meta, TikTok) y de monetización (YouTube "inauthentic content", 2025) castigan el mismo video replicado en N cuentas. Cuentas de nichos diferenciados con variantes por cuenta = legítimo y seguro.

Lo esencial de cada API

TikTok — Content Posting API

  • Cada cuenta autoriza por OAuth individual (access token de 24 h, refresh de 365 días — rotación continua).
  • En el formulario de auditoría se declara cuántos creadores activos tendrá la app: declarar la meta de 50–100 desde el inicio.
  • Conflicto a decidir por cuenta: Creator Rewards (monetización) exige cuenta personal; la demografía por API exige cuenta Business. No hay ambas a la vez.

Instagram — Graph API

  • Dos variantes: con Instagram Login (sin página de Facebook — la vía simple para cuentas nuevas) o con Facebook Login.
  • Flujo contenedor → publish con URL pública del video; Reels de 3 s a 15 min, ≤300 MB.
  • Límite verificable en vivo por cuenta con content_publishing_limit.

Facebook — Reels Publishing API

  • Tokens de system user del Business Manager no caducan — la mejor base para automatizar; 100 páginas caben en un solo Business Manager verificado.
  • Permite crossposting de un video entre páginas sin re-subirlo.
  • Meta viene recortando métricas (2024–2026): construir sobre media_view y page_follows, no sobre impressions/reach.

YouTube — Data API + Analytics API

  • No hay flag "Short": todo video ≤3 min, cuadrado o vertical, se clasifica solo.
  • Cuota nueva (jun-2026): 100 subidas/día por proyecto. 100 cuentas × 1 Short diario = justo el tope → pedir extensión al escalar.
  • La mejor analítica de las cuatro: edad × sexo × país por video (una consulta por video), con cuota independiente.

Reglas del juego: políticas y monetización

  • Multi-cuenta legítima = camino empresarial. Los límites "3 cuentas por dispositivo" (TikTok) o "5 por app" (Instagram) son de las apps móviles. A escala se opera con Meta Business Manager (system users), TikTok Business Center y canales de marca de YouTube.
  • Lo que banea es el patrón, no la cantidad. Redes de cuentas que simulan independencia, se amplifican entre sí o publican contenido idéntico. Nichos temáticos con identidad transparente y variantes por cuenta = seguro.
  • Etiqueta de IA obligatoria en TikTok, YouTube y Meta para contenido realista generado o alterado con IA (auto-detección por metadatos C2PA). Omitirla reiteradamente conlleva sanciones. Contenido claramente estilizado no la requiere.
  • La monetización nativa subió el listón para contenido IA. YouTube exige originalidad ("inauthentic content", 2025) y 1.000 subs + 10 M vistas de Shorts/90 días; TikTok Creator Rewards exige 10.000 seguidores y cuenta personal; Facebook ~10.000 seguidores. El modelo de ingresos más robusto para esta operación es el previsto: campañas con marcas y referidos, donde lo que vale es el alcance demostrable — justo lo que mide el dashboard.

Plan por fases

Fase 1 · validar
5 cuentas, ~$0–35/mes en APIs
  • Crear 5 cuentas con nichos temáticos diferenciados
  • Registrar apps (Meta, TikTok, Google) e iniciar auditorías el día 1
  • Publicar TikTok vía Higgsfield; IG/FB/YT vía agregador o apps propias
  • Recolector diario de métricas → Postgres
Fase 2 · escalar
50–100 cuentas con apps auditadas
  • Apps propias auditadas publicando en las 4 plataformas
  • Pipeline de variantes por cuenta (hook, voz, idioma) sobre cada asset
  • Extensión de cuota de YouTube; varios portfolios de Meta si hace falta
  • Dashboard con data real → media kit para campañas con marcas

El dashboard

El mock interactivo ya está construido con la estructura definitiva: KPIs del período, alcance diario por red, audiencia por edad y sexo, alcance por país, % de audiencia nueva, ranking de cuentas y top videos — todo filtrable por período, red, país, edad, sexo y tipo de usuario.

Abrir el mock del dashboard → Datos simulados deterministas; con data real solo se reemplaza la fuente. La demografía se calcula como alcance estimado (alcance × distribución reportada por cada API).
